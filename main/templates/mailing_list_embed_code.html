1. A plain form

Paste this into the other site. Nothing loads from us, so it cannot slow that page down or break when we redeploy. The full version with comments is at {{ snippet_url }}.

<form method="post" action="{{ action }}">
  <label for="pcf-signup-email">Subscribe to {{ area.name }}</label>
  <input id="pcf-signup-email" type="email" name="email" required
         placeholder="you@example.com" autocomplete="email">
  <input type="hidden" name="interest" value="{{ area.slug }}">
  <input type="hidden" name="source" value="external-site">
  <div style="position:absolute;left:-5000px;" aria-hidden="true">
    <input type="text" name="website" tabindex="-1" autocomplete="off">
  </div>
  <button type="submit">Subscribe</button>
</form>

After submitting, the visitor lands on a thank-you page here. To send them back to the other site instead, add <input type="hidden" name="next" value="https://example.org/thanks"> over https. That is only honoured for sites we have been told about, so an open redirect cannot be built out of it. Already set up{% if redirect_hosts %} (with or without www.){% endif %}:
